# Thala 7 – Sneaker Store (CSS Mini Project)

A 4-page sneaker store built with HTML, CSS (Flexbox) and a little JavaScript.

## Pages
- `index.html` – Landing page: navbar, hero section (two divs), orange service-overview strip
- `product.html` – Product display: main image, details, price, quantity, Add to Cart, scrolling gallery
- `cart.html` – Shopping cart: table with remove icon, coupon card, totals, Pay Now, Continue Shopping
- `checkout.html` – Checkout: email, payment methods (Card/Crypto/Bank), card fields, order summary

## Files
`style.css` (all styling), `script.js` (cart totals, quantity, remove, coupon), `images/` (shoe illustrations).

## Try it
Open `index.html` in a browser. Coupon code `THALA7` gives 10% off.
